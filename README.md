# 机器人维护台

机器人维护台是面向小型机器人研发团队、实验室和工作室的本地维护工具。它根据每台设备实际装配的关键部件及版本筛选资料，帮助维护者把故障现象、工单依据和复测结果留给下一位接手者。

## 运行试用版

下载或克隆本仓库。电脑装有 Python 3 后，在仓库根目录双击 `start-pilot.cmd`（Windows），或者在终端运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory pilot
```

Windows 终端也可以将 `python3` 写为 `python`。保留终端窗口，然后[打开本地维护台](http://127.0.0.1:8765/)。

## 十分钟体验

1. 分别选择演示机器人 A 和 B，对两台同型号、不同控制板的设备输入「前进时右腿动作不稳定」，比较草稿引用。
2. 选择控制板版本未知的机器人 C，观察草稿会追问什么。也可以主动登记一次配置变更，再确认旧草稿需要重新核对。
3. 确认一张工单，记录复测，在维修历史里核对工单依据、起草时的配置和复测时的配置。
4. 添加一台自己的设备，录入资料摘录并指定适用型号、部件和版本。有需要时从侧栏导出或导入 JSON 备份。

## 实现范围

试用版用 JavaScript 规则按型号、关键部件及版本筛选人工录入的资料，并起草待核实事项。它无需设备连接或模型密钥。数据保存在打开该地址的浏览器中，换浏览器时可以用 JSON 备份转移。示例设备配置、资料摘录和工单供模拟演练。

## 参与贡献

欢迎提交可复现的问题和改动。报告资料匹配问题时，请写明设备型号、关键部件、当前版本、预期引用和实际引用。贡献示例时使用自制或获准公开分发的资料，并删除真实设备识别信息。

代码在 `pilot/` 下。`core.js` 处理配置、资料适用性和工单记录，`app.js` 负责界面和浏览器存储。
